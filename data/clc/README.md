# 中图法第五版本地索引

| 文件 | 说明 |
|------|------|
| `clc.json` | 树形结构（22 个大类，约 45785 条） |
| `clc_index.json` | 扁平索引：`类号 -> 官方类名`，供程序校验 DeepSeek 返回的分类路径 |

数据来源：[acdzh/Chinese-Library-Classification](https://github.com/acdzh/Chinese-Library-Classification)（据《中国图书馆分类法》第五版整理，仅供研究使用，禁止商业用途）。

## 校验规则

分类完成后校验规则：

1. 「分类号」须在 `clc_index.json` 中存在  
2. 若模型给出了「最优分类路径」，则**路径末级类号**须与「分类号」一致（中间层级类名允许与索引不完全相同）

- **通过** → 写入 `结果.txt`，图书移入对应分类号目录（保留模型返回的路径；仅当路径为空时用索引补全）
- **未通过** → 写入 `待进行分类.txt`，图书移入 `待分类/` 目录
